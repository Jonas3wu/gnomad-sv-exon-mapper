The MANE Select transcript is listed first and selected by default, followed by RefSeq Select and curated RefSeq. To use a different transcript, enter its accession (e.g. NM_ number) to auto-select it. Uses MyGene.info (gene location) and the UCSC Genome Browser API (exon coordinates). Needs internet access from your browser; if your network blocks it, use Paste UCSC row.

In the UCSC Table Browser: choose the genome, group Genes and Gene Predictions, track NCBI RefSeq, table RefSeq Select (or the MANE track), region = your gene symbol, output format all fields from selected table. Copy the row for your transcript (header optional).

Limits — read before using results

  • Transcript and build must match. Exon numbers and coding status follow the transcript you load; MANE Select is the default; switch if you describe variants against another transcript. gnomAD SV records are genomic, so no conversion to MANE is needed, but gnomAD's own consequence labels follow its transcript and may number exons differently. gnomAD SV v4.1 is GRCh38 and v2.1 is GRCh37; a mismatch shifts every exon.
  • Breakpoints are approximate. gnomAD-SV breakpoint precision varies by evidence type. Calls with a breakpoint inside an exon, and frame estimates marked ~, should be checked against the record.
  • Frame is arithmetic only. Coding nt affected mod 3, assuming a simple deletion or a tandem duplication. Splicing, NMD, and PVS1 decision rules (e.g. the ClinGen SVI recommendations: start loss, last/penultimate exon, >10% of protein) are not applied; flags point to where they matter.
  • Small exon-level events are under-represented in population SV callsets (median gnomAD SV is a few hundred bp), so absence here is weaker evidence than for an SNV.
  • This is not a classification. How population SV data applies to criteria such as PM2 or BA1/BS1 depends on your own guidelines; treat matches as supporting information, not as a criterion on their own.
  • Pasted data stays in your browser. Transcript lookup sends only the gene symbol and region to MyGene.info and UCSC; Fetch from gnomAD sends only the gene symbol and dataset to gnomAD.
